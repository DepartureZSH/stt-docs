# 从这里开始

时奕智能教务系统帮助学校完成基础数据准备、课程计划配置、约束管理、智能排课、结果校验与导出。

> **第一次使用**
>
> 先用五分钟认识平台，再跟随完整流程完成第一个排课项目。

## 推荐阅读路径

1. [快速了解](./user-guide/quick-start.md)
2. [账号、机构与项目](./user-guide/accounts-organizations-projects.md)
3. [完整排课流程](./user-guide/complete-workflow.md)
4. 按需查看具体页面手册
