# 教室设置页面操作手册

## 1. 页面用途

教室设置页维护教室类型、具体教室、容量和不可用时间。课程计划会从这里选择默认教室或课次自定义教室，算法会据此避免教室冲突和不可用时间。

建议先创建教室类型，再创建具体教室。

## 2. 教室类型

### 新增类型

1. 在左侧选择“教室类型”。
2. 输入类型名称，例如“普通教室”“实验室”“音乐教室”。
3. 输入说明。
4. 点击“保存教室类型”。

### 编辑和删除

在台账中点击“编辑”修改名称或说明。删除前确认没有教室仍引用该类型。

类型用于分类和选择，不等于具体可用空间；算法实际安排的是具体教室。

## 3. 新增教室

1. 在左侧选择“教室”。
2. 输入教室名称。
3. 选择教室类型。
4. 输入容量。
5. 如有停用时间，点击“选择不可用时间”。
6. 完成不可用规则后返回表单。
7. 点击“保存教室”。

教室名称建议使用校内可识别的真实名称或编号。

## 4. 设置教室不可用时间

不可用时间表示该教室绝不能安排课程。

### 新增单个规则

1. 在教室表单点击“选择不可用时间”。
2. 选择周频率：全学期、单周、双周、前半学期、后半学期，或逐周选择。
3. 选择星期。只会显示“课表设置”中启用的星期。
4. 选择具体时间段。
5. 点击“添加不可用时间”。

### 批量添加时间段

1. 点击“批量添加时间段”。
2. 使用“全时段”“仅上午”“仅下午”等预设，或逐项选择多个节次。
3. 点击“添加所选时间段”。
4. 完成后退出批量模式。

### 编辑规则

1. 在教室表单的不可用时间列表找到规则。
2. 点击“编辑”。
3. 修改周频率、星期或时间段。
4. 点击“保存修改”。

### 删除或清空

- 单条删除：点击规则旁的“删除”。
- 全部清空：点击不可用时间区域的“清空”。

清空后必须再次保存教室，才能把修改写入项目。

## 5. 与课表模板的关系

- 不可用星期来自当前周课程表模板。
- 不可用节次来自模板中的课程行。
- 模板隐藏的星期不能在这里选择。
- 修改模板节次后，应回到教室页检查原有不可用规则是否仍然准确。

## 6. 教室使用策略

在课程计划中：

- “不使用教室”用于不需要平台分配空间的任务。
- “使用教室”时应添加一个或多个默认教室。
- 某个课次可选择“默认教室”，也可改成“自定义教室”。

如果课程需要教室却没有任何候选教室，排课前清单会给出警告，结果校验可能出现缺少教室。

## 7. 完成检查

- 所有具体教室都已选择类型。
- 容量数据合理。
- 专用教室和临时占用的不可用时间已设置。
- 周六、周日规则与课表模板一致。
- 不可用规则没有误选整学期或全部时段。
- 修改不可用规则后已保存教室。

## 8. 常见问题

### 找不到某个星期

到“课表设置”启用该星期并保存模板。

### 找不到某个节次

确认节次在当前模板中存在且启用。

### 添加规则后台账没有变化

弹出栏中的“添加不可用时间”只把规则加入当前教室表单；还需点击“保存教室”或“保存修改”。

### 课程仍被安排到不合适的空间

检查课程任务的默认教室、课次自定义教室和教室不可用时间是否都已保存，然后重新排课。
