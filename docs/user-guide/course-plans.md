# 课程计划页面操作手册

## 1. 页面用途

课程计划页把基础数据组合成可以排课的实际任务。它包含三个层次：

- 课程计划：某个行政班需要开设某个科目。
- 授课任务：该班该科由哪位教师承担，是否使用教室，可选哪些默认教室。
- 课次：实际进入算法的一节课，包含启用状态、候选时间和课次教室。

同一班级同一科目可以有多个授课任务，用于多位教师共同承担。

## 2. 选择配置模式

### 按班级配置

适合逐班维护课程。先选择行政班，再逐门选择科目和授课教师。第一次录入建议使用此模式。

### 按教师配置

适合根据教师工作量表录入。先选择教师，再选择班级和科目。教师由左侧选择锁定。

两种模式操作同一批数据；切换模式不会复制数据。

## 3. 按班级配置课程

### 选择班级和科目

1. 在左侧选择行政班。
2. 在中间选择科目。
3. 中间列表显示该科目的教师摘要、课次数量和配置状态。
4. 右侧显示已有授课任务或新增入口。

“其他任务”区域可能显示由教师工作量方式产生的辅助任务。

### 新增授课任务

1. 选择班级和科目。
2. 点击“新增授课老师”或进入正在新增状态。
3. 搜索教师姓名或分组标签，选择教师；也可暂时选择“未指定教师”。
4. 配置教室策略。
5. 编辑课次。
6. 点击“新增授课任务”。

正式排课前应尽量补齐未指定教师。

### 编辑已有授课任务

1. 在右侧任务切换区选择某位教师的任务。
2. 修改教师、教室或课次。
3. 点击“保存授课任务”。

### 删除授课任务或科目计划

- 点击任务行的“删除”只删除该授课任务。
- 点击“删除科目计划”会删除该班该科计划及其关联任务和课次。

删除前检查是否还有另一位教师承担该科目。

## 4. 从其他班级导入

适合班级课程结构相近的场景。

1. 选择目标班级。
2. 在“从其他班级导入”中选择来源班级。
3. 点击“一键导入”。
4. 确认覆盖提示。
5. 导入后逐门分配教师。

导入会复制来源班级的课程结构和课次设置，但教师初始化为“未指定”。目标班级同科目原有配置可能被覆盖，操作前先确认。

## 5. 配置教师

教师选择器支持按姓名或分组标签搜索。选择“未指定教师”可暂存任务，但排课前会显示警告。

同一班同一科由多人承担时，为每位教师分别新增授课任务，并分别维护各自课次。

## 6. 配置默认教室

### 不使用教室

选择“不使用教室”表示平台不为该任务分配物理空间。仅在业务上确实不需要教室时使用。

### 使用教室

1. 选择“使用教室”。
2. 搜索并添加一个或多个默认教室。
3. 点击标签上的“×”可移除教室。

多个默认教室表示算法可在这些候选中选择。使用教室但未添加候选教室会产生警告。

## 7. 从其他课程导入课次设置

1. 在“从其他课程导入课次设置”选择已配置课程。
2. 点击“导入课次设置”。
3. 核对导入的课次、候选时间和教室设置。
4. 保存当前授课任务。

导入不会覆盖当前任务教师。

## 8. 编辑课次

1. 点击“编辑课次”。
2. 在底部弹出栏查看现有课次。
3. 点击“新增课次”增加一节。
4. 修改课次名称。
5. 使用“启用”控制是否进入排课。
6. 使用“复制课次”快速复制相似设置。
7. 使用“删除课次”移除不需要的课次。
8. 完成后点击“完成”。
9. 回到右侧点击“保存授课任务”。

仅点击弹出栏“完成”不会把改动写入项目；最后保存授课任务是必要步骤。

## 9. 设置课次候选时间

### 默认行为

不设置候选时间时，课次默认可以安排在所有满足基本条件的时间。

### 设置候选时间

1. 在课次卡片点击“选择期望时间”。
2. 选择周频率：全学期、单周、双周、前半学期、后半学期或逐周选择。
3. 选择候选优先级。
4. 点击周候选时间表中的格子；再次点击可取消。
5. 可用预设快速选择上午、下午或全部可行时间。
6. 点击“保存”。
7. 返回课次编辑后点击“完成”。
8. 最后保存授课任务。

一旦设置候选时间，该课次只会在已选候选范围内排课。不要因为只选了“最喜欢”的两个格子而无意中排除其他可行时间。

### 候选优先级

- 最高优先：惩罚 0，优先安排。
- 普通优先：惩罚 10，可接受。
- 较低优先：惩罚 30，尽量少用。
- 兜底可排：惩罚 60，最后选择。

颜色越浅表示优先级越高。优先级影响质量分，不等同于硬性禁止。

### 时长不足

如果当前课次课长超过所有节次可用时长，所有格子会被禁用。应调整科目/课次课长或课表设置中的节次时间。

## 10. 设置课次教室

### 默认教室

课次沿用授课任务的默认教室列表。

### 自定义教室

1. 将课次教室模式切换为“自定义教室”。
2. 搜索并添加一个或多个教室。
3. 保存课次编辑和授课任务。

自定义教室只影响当前课次，适合实验课、体育课等特殊安排。

## 11. 按教师配置

1. 切换“按教师配置”。
2. 从左侧选择教师。
3. 选择班级和科目。
4. 点击“添加/配置课程”。
5. 配置默认教室、导入或编辑课次。
6. 点击“新增本教师任务”或“保存授课任务”。

此模式中教师由左侧选择决定。若需要为同一班同一科添加另一位教师，应切换到该教师或使用按班级模式。

## 12. 完成检查

- 每个需要开设的班级科目都有计划。
- 每个计划至少有一个授课任务。
- 每个任务有正确教师或明确的待分配状态。
- 每个任务有实际启用课次。
- 课次数量符合周课时资料。
- 需要教室的任务已有候选教室。
- 不需要教室的任务明确选择“不使用教室”。
- 候选时间没有过窄，周频率正确。
- 弹出栏修改后已经保存授课任务。
