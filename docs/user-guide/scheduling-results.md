# 排课运行与候选课表操作手册

## 1. 页面用途

排课运行页负责排课前检查、创建运行、查看进度、校验结果、浏览候选课表、导出 Excel 和人工微调。

重新排课会产生新的候选结果。运行期间旧候选课表可能被清空，正式操作前应先保存需要保留的导出文件。

## 2. 发起排课前检查

1. 确认页面顶部当前项目。
2. 点击“发起排课”。
3. 查看排课前数据清单。

### 数据统计

清单统计教师、班级、科目、教室、课程计划、授课任务、课次和约束，并提示同名教师、未指定教师等情况。

### 必须处理

常见阻塞包括：

- 未选择项目。
- 缺少周课程表模板。
- 当前模板没有启用节次。
- 缺少教师、班级、科目或教室。
- 缺少课程计划、授课任务或课次。

### 建议处理

常见警告包括：

- 授课任务未指定教师。
- 使用教室的任务没有默认教室。
- 启用约束无法编译或状态异常。

即使“继续排课”按钮可用，也应先处理清单中显示为阻塞或高风险的项目。

## 3. 临时 JSON 项目快照

排课前可以：

- 点击“立即下载”单独保存当前项目快照。
- 勾选“继续排课时同时下载此 JSON 快照”。

快照包含学期、课表模板、学校数据、教室、课程计划、课次和约束。它不包含账号、机构成员、历史运行、候选课表、人工微调、算法日志或 XML 文件。

该快照适合检查和留档。当前“导入数据”功能仍为入口占位，不能用它恢复项目。

## 4. 发起和终止排课

### 发起

1. 处理清单问题。
2. 点击“继续排课”。
3. 系统生成输入、提交算法并解析结果。

### 状态说明

- 尚未发起：当前项目没有运行。
- 已排队：等待后台任务处理。
- 运行中：正在生成输入、运行算法或解析结果。
- 已完成：候选课表已生成。
- 运行失败：检查错误说明、输入数据和服务状态。
- 已终止：用户取消，本次没有新的候选结果。

### 终止

运行中点击顶部“终止排课”。终止后可处理数据并重新发起。

### 重新排课

运行完成、失败或取消后，可点击“重新排课”。重新排课前建议确认上一次问题已处理。

## 5. 查看运行阶段和输入摘要

运行步骤包括：

1. 准备数据输入。
2. 运行算法。
3. 解析候选课表。

输入摘要显示课次、教室和约束数量。数量明显少于预期时，不要只等待算法，应返回课程计划或约束页检查数据。

## 6. 校验结果

### 核心指标

- 质量：时间、教室和软约束惩罚之和，通常越低越好。
- 未排入：没有分配时间的课次。
- 无教室：需要教室但没有分配教室的课次。
- 硬约束：必须满足规则的违反数量。
- 软约束：偏好规则的违反数量。

### 结果判定

可交付结果至少应满足：未排入为 0、无教室为 0、硬约束为 0。

软约束可不为 0。展开“质量明细”查看时间优先级、教室选项和软约束惩罚，判断是否值得调整数据后重新排课。

### 重新校验

候选结果存在时，可点击“重新校验”。人工移动课次后系统也会重新计算，仍应手动复核最新指标。

## 7. 候选课表视图

### 全课表

显示当前周的全部可见课次，适合总体检查资源重叠和分布。

### 按班级

1. 点击“按班级”。
2. 从下拉框选择班级。
3. 检查课程覆盖和每日分布。

### 按教师

1. 点击“按教师”。
2. 从下拉框选择教师。
3. 检查冲突、空档和工作量分布。

### 切换周次

点击周次数字或左右箭头。单双周或分周规则存在时，必须抽查多个周次。

## 8. 缓冲区

缓冲区用于暂存课次，也显示尚未排入正常课表的课次。

- 把课次拖入缓冲区可临时移出课表。
- 缓冲区课次可再拖到时间槽。
- 交付前缓冲区应为空，或明确说明为何仍有待安排课次。

## 9. 人工移动课次

### 拖拽方式

1. 拖动课次。
2. 放到空时间槽、另一课次位置或缓冲区。
3. 查看确认窗口中的当前位置、目标位置和警告。
4. 点击“确认移动”。

### 点击方式

1. 点击课次选中。
2. 点击目标空时间槽、目标课次或缓冲区。
3. 确认移动。
4. 不移动时点击“取消选择”。

### 移动后的检查

确认后系统保存课次位置并重新计算校验和质量。立即检查：

- 是否新增硬约束违反。
- 是否造成教师、班级或教室冲突。
- 是否违反候选时间或教室要求。
- 质量是否明显变差。

不要仅凭页面上“看起来合适”就跳过校验。

## 10. 导出 Excel

### 导出全课表

点击“导出全课表”。

### 导出班级

点击“导出班级”。系统按班级生成对应课表；没有班级数据时按钮不可用。

### 导出教师

点击“导出教师”。系统按教师生成对应课表；没有教师数据时按钮不可用。

导出使用“课表设置”的星期、节次、自定义行列和课程单元格显示规则。下载后应抽查：

- 文件能正常打开。
- 学期、星期和节次正确。
- 课程、教师、教室和班级字段符合导出设置。
- 合并、自定义行列没有破坏布局。
- 多周规则在各文件/工作表中表达正确。

## 11. 导入数据入口说明

“导入数据”当前仅提供：

- 选择 `.json` 文件。
- 检查扩展名和显示文件信息。
- 展示未来单 JSON 项目配置结构。

当前不会解析业务内容、写入数据库或覆盖项目。“项目数据导入功能后续实现”按钮不可用。

## 12. 失败排查顺序

1. 查看运行错误说明。
2. 打开排课前数据清单，处理阻塞项。
3. 检查课次是否存在且启用。
4. 检查候选时间是否过窄、课长是否能放入节次。
5. 检查需要教室的任务是否有候选教室。
6. 检查教室不可用范围是否过大。
7. 检查新加硬约束是否互相矛盾。
8. 刷新页面或重新校验。
9. 若仍失败，由管理员检查后台 worker、算法服务和日志。

- 周次切换和缓冲区。
