# 约束配置页面操作手册

## 1. 页面用途

约束用于表达课次之间必须满足或尽量满足的规则。页面同时显示系统自动生成的保障约束和用户创建的自定义约束。

自动约束只读，用于保证教师、班级、教室等基本不冲突。自定义约束可新建、编辑、停用或删除。

## 2. 认识硬约束和软约束

### 硬约束

必须满足，违反时结果不可接受。适合安全、资源冲突和不可违反的业务规则。

### 软约束

允许违反，但会增加惩罚分。适合偏好、均衡和“尽量”类要求。

不要把所有偏好都设置为硬约束。硬约束过多或互相矛盾可能导致没有可行课表。

## 3. 查找和查看约束

### 筛选

- 关键词：搜索名称、类型、对象或状态。
- 来源：全部、自动生成、自定义。
- 权限：全部、可编辑、不可编辑、已停用。

### 查看详情

1. 单击约束列表中的记录。
2. 在右侧查看类型、强度、权限和作用范围。
3. 查看关联教学任务或课次。
4. 查看编译原因或状态说明。

自动约束没有编辑按钮。自定义约束可点击“编辑”，也可在列表中双击进入编辑。

## 4. 使用常见约束新建

1. 点击“新建”。
2. 保持“常见约束”标签。
3. 选择场景。
4. 输入易理解的约束名称。
5. 从左侧可选课次逐项加入，或按当前筛选全部加入。
6. 在右侧已选课次中复核，并移除误选项。
7. 必须满足时勾选“硬约束”。
8. 作为偏好时取消硬约束并填写违反扣分。
9. 阅读自然语言摘要。
10. 点击“生成约束”。

### 当前常见场景

- 课程连续排课。
- 课程不连续排课。
- 教师不可用时间。
- 课程分散到不同天。
- 课程固定/候选时间。

部分场景的具体时间能力可能由课程候选时间或后续版本承载。保存后应查看编译状态，不要只看名称。

## 5. 使用 ITC2019 约束新建

1. 点击“新建”。
2. 切换到“ITC2019约束”。
3. 输入名称。
4. 选择约束类型。
5. 选择关联课次。
6. 设置硬约束或软约束及扣分。
7. 阅读自然语言摘要。
8. 展开“查看 ITC2019 编译预览”进行高级核对。
9. 点击“新增约束”。

当前界面提供的类型包括：不要时间重叠、必须在同一间教室、不能同一天上课、必须先后上课、不能同时开始、必须在同一天上、要同时开始、要同时进行。

普通用户优先使用中文场景；只有在明确理解课次关系时才使用高级类型。

## 6. 使用高级模板

1. 点击“新建”。
2. 切换到“高级模板”。
3. 用名称、标签、说明或分类搜索模板。
4. 可收藏常用模板。
5. 点击“导入”。
6. 根据导入结果补充对象和参数，并保存。

模板来自管理员发布的约束模板库。导入后仍需核对作用范围和强度。

## 7. 编辑和删除自定义约束

### 编辑

1. 选择自定义约束。
2. 点击“编辑”或双击记录。
3. 修改名称、类型、关联课次、硬/软属性或扣分。
4. 点击“保存修改”。

### 删除

1. 进入编辑状态。
2. 点击“删除”。
3. 确认不再需要该规则。

自动生成约束不可编辑或删除。

## 8. 约束设计建议

- 名称包含对象和意图，例如“一年级1班数学分散到不同天”。
- 连续、同日、先后等关系要选择正确的课次集合和顺序。
- 教师或班级绝不能冲突的规则使用系统自动约束，不重复创建。
- 偏好用软约束，扣分用于表达相对重要性。
- 新增硬约束后先少量试排，确认不是互相矛盾。
- 不可编译、无关联课次或已停用的约束不会按预期进入排课。

## 9. 保存后检查

- 列表来源显示正确。
- 作用范围中的课次与预期一致。
- 强度是硬约束或正确扣分的软约束。
- 编译状态可用，没有错误原因。
- 没有与已有硬约束互相矛盾。

## 10. 常见问题

### 找不到要选的课次

先到“课程计划”确认授课任务和课次已经保存且启用，再刷新约束配置。

### 约束显示不可编辑

自动约束只读。自定义约束才有编辑权限。

### 保存按钮不可用

至少要选择一个关联课次；某些成对关系通常需要两个或更多课次才有意义。

### 排课失败或无解

优先检查新加的硬约束是否互相矛盾、候选时间是否过窄、教室不可用范围是否过大。可把偏好改为软约束后重新排课。
