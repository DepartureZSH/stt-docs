# 文档总览

## 1. 文档目的

本套文档面向平台试用用户、教务人员、排课负责人、机构管理员和平台管理员，说明当前版本已经可以在界面中完成的操作。

## 2. 建议阅读路径

### 第一次了解平台

1. 阅读《快速了解》。
2. 阅读 **新手指南** -《完整排课流程》。
3. 按需打开具体页面手册。

### 第一次实际排课

1. **新手指南** -《账号、机构与项目使用指南》：登录、进入机构、创建项目。
2. **数据录入** -《课表设置页面操作手册》：设置学期、星期和节次。
3. **数据录入** -《学校数据页面操作手册》：录入教师、班级和科目。
4. **数据录入** -《教室设置页面操作手册》：录入教室类型、教室和不可用时间。
5. **数据录入** -《课程计划页面操作手册》：配置授课任务、课次、候选时间和教室。
6. **数据录入** -《约束配置页面操作手册》：检查自动约束并添加自定义约束。
7. **排课输出** -《排课运行与候选课表操作手册》：排课、校验、导出和人工微调。

### 使用 AI 辅助配置

在了解基础对象关系后阅读 **数据录入** -《AI智能体使用指南》。AI 生成的写入操作必须由用户确认，不会绕过确认直接修改项目数据。

### 管理机构和成员

普通用户阅读 **新手指南** -《账号、机构与项目使用指南》；机构管理员和平台管理员再阅读 **多人合作**《管理员操作指南》。

## 4. 当前版本页面地图

- 平台主页：产品介绍、注册和登录入口；“联系合作”“软件下载”仍为占位说明。
- 登录、注册、重置密码。
- 工作台：机构上下文、项目列表、项目数据统计和完整流程指引。
- 课表设置。
- 学校数据。
- 教室设置。
- 课程计划。
- 约束配置。
- 排课运行与候选课表。
- AI 智能体。
- 个人中心、加入机构、注册机构、机构管理。
- 平台审核：仅平台管理员可见。

## 5. 截图处理约定

本次交付不包含截图。各页面文档末尾列出建议截图清单，后续补图时应遵循以下原则：

- 使用脱敏演示机构和演示项目。
- 不展示真实邮箱、手机号、微信号、机构地址或学生信息。
- 截图中的字段和按钮名称必须与当前发布版本一致。
- 优先截完整操作区域，再补充必要的局部放大图。
- 页面更新后同步更换截图和文档版本日期。

## 6. 文档维护规则

- 页面按钮、字段、状态或业务规则变更时，修改对应页面文档和《03-完整排课流程》。
- 新增或下线功能时，更新本文件的页面地图和《13-现有参考资料索引》。
- 文档中“当前版本未开放”的内容只有在界面可操作并完成验证后才能改为正式步骤。
- 以当前发布代码和实际验收结果为最终依据；规划文档只能用于解释背景。
