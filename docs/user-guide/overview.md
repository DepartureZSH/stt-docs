# 使用指南

不用先学会所有功能。先把一个班级配置好，再复制到其他班级，最后排课和导出。

## 第一次使用

1. [注册、登录和选择项目](./start/accounts-organizations-projects.md)。
2. [跟着完整流程做一次排课](./start/complete-workflow.md)。
3. 遇到不明白的词，查看[常见问题](./faq-glossary.md)。

[![工作台：先选择项目，再进入左侧各个功能](../../static/screenshot/guide/workbench.png)](../../static/screenshot/guide/workbench.png)

## 看图时请注意

- 截图来自独立演示账号，教师姓名已替换为“教师001”等编号，联系方式已清空。操作时请填写自己学校的数据。
- 看不清按钮时，点击图片可打开原图放大查看。
- 看到保存成功提示或列表更新，才算完成。页面右上角的 **新手指南** 也能帮你找到操作位置。
