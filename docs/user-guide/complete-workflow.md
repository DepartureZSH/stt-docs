# 完整排课流程

## 1. 选择排课路径

### 第一次标准排课

第一次标准排课按以下顺序进行：

1. 创建或选择项目。
2. 设置学期和周课程表模板。
3. 维护教师、班级和科目。
4. 维护教室类型、教室和不可用时间。
5. 配置课程计划、授课任务和课次。
6. 检查自动约束并添加自定义约束。
7. 打开排课前数据清单。
8. 生成临时项目快照并发起排课。
9. 查看运行状态、校验和候选课表。
10. 导出或人工微调，微调后重新确认校验结果。

AI 智能体可辅助维护基础数据、课程计划和约束，但不是必经步骤；所有变更仍需用户核对并确认执行。

### 后续排课

后续排课先判断是继续修改当前排课任务，还是开始一个新的学期或独立任务。无论选择哪一种，课表模板、教师、班级、科目、教室类型、教室和教室不可用时间都使用本机构已经持久化的数据，不需要从零重新录入。

两条路径都先完成以下检查：

1. 对照本次实际情况，列出课表模板、教师、班级、科目和教室数据发生的变化。
2. 在本机构对应的“课表设置”“学校数据”和“教室设置”页面，只对变化项进行新增、删除或修改。
3. 没有变化的数据直接沿用，不重复创建或批量导入。

#### 同一项目修改后重新排课

适用于教师、课次、教室、候选时间或约束发生调整，但仍属于同一个学期和排课任务的情况。

1. 先导出需要保留的全课表、班级课表和教师课表；重新排课时，旧候选课表可能被清空。
2. 确认当前机构和项目，并完成上述机构持久化数据的局部调整。
    1. 对照本次实际情况，列出课表模板、教师、班级、科目和教室数据发生的变化。
    2. 在本机构对应的“课表设置”“学校数据”和“教室设置”页面，只对变化项进行新增、删除或修改。
    3. 没有变化的数据直接沿用，不重复创建或批量导入。
3. 在“课程计划”页面，对当前项目的课程计划、授课任务和课次进行局部新增、删除或修改。
4. 在“约束配置”页面，对当前项目的自定义约束进行局部新增、删除或修改，并检查自动约束和约束编译状态。
5. 修改模板星期、节次或课程课长后，重新检查相关课次的候选时间；修改教师、班级、科目或教室后，重新检查授课任务、课次教室和关联约束。
6. 进入“排课运行”，点击“重新排课”，检查排课前数据清单并处理阻塞项。
7. 需要留档时下载本次项目数据文件，然后继续排课。
8. 排课完成后重新检查未排入、缺少教室、硬约束违反、软约束违反和质量明细。
9. 与上一次导出的课表对照抽查受影响班级和教师，必要时继续局部调整并再次排课。
10. 确认结果可用后重新导出，并用日期或版本号区分文件。

#### 新学期或新的独立排课任务

1. 保留旧项目，不要为了开始新任务直接删除旧项目；先完成所需课表导出和留档。
2. 在工作台创建新项目，名称应能区分学期或任务，例如“2026 秋季排课”。
3. 选择新项目并确认页面顶部的当前项目名称。
4. 复用本机构已有的课表模板、教师、班级、科目和教室数据，只对新学期或新任务发生变化的部分进行新增、删除或修改。
    1. 对照本次实际情况，列出课表模板、教师、班级、科目和教室数据发生的变化。
    2. 在本机构对应的“课表设置”“学校数据”和“教室设置”页面，只对变化项进行新增、删除或修改。
    3. 没有变化的数据直接沿用，不重复创建或批量导入。
5. 在新项目中重新走课程计划、授课任务和课次的配置流程；这些项目内配置不能直接沿用旧项目结果。
6. 检查新项目的自动约束，并按本次任务要求配置自定义约束。
7. 打开排课前数据清单，处理阻塞项并按需下载临时数据文件。
8. 发起排课，完成结果校验、抽查、导出和必要的人工微调。

项目可以通过临时数据文件恢复。（待开发，未上线）

AI 智能体可以辅助生成新项目的课程计划、授课任务、课次和约束草稿，但必须逐项核对后确认执行。

无法确认是否应沿用当前项目时，优先新建项目。一个项目只承载一个学期或一次明确的排课任务，更便于留档和追溯。

## 2. 排课前准备

第一次标准排课建议收集准备的数据：

- 学期名称和总周数。
- 学校每周上课日和每天节次时间。
- 教师名单及分组标签，如：张三 - 数学组，班主任。
- 行政班名称和人数。
- 科目名称及默认课长。
- 教室类型、教室名称、容量和不可用时间。
- 每个班每门课程的授课教师、周课次数、教室需求。
- 必须满足的规则和可接受但不理想的偏好。

如果资料是表格或文字，可在 AI 智能体中上传或粘贴，先生成预览，再逐条确认。

后续排课不需要重复准备全部基础资料：沿用当前项目时准备“变化清单”；新学期或新任务除基础数据变化清单外，还应准备本次完整的课程计划、授课安排和约束要求。

## 3. 第一步：创建或选择项目

在工作台确认机构后，新建项目或选择已有项目。进入任一业务页面时检查顶部“当前项目”。

完成标准：项目名称能够明确区分学期或排课任务。

## 4. 第二步：课表设置

第一次排课时建立学期和周课程表模板；后续排课直接复用本机构已有模板，只对实际变化的星期、节次、时间或导出样式进行局部新增、删除或修改。

1. 设置学期名称和周数。
2. 新建或选择周课程表模板。
3. 设置模板名称，必要时设为默认模板。
4. 启用实际上课的星期。
5. 新增课程行并设置每节开始、结束时间。
6. 按需添加午休、课间操、备注等自定义行列。
7. 设置导出时课次单元格的两行显示字段。
8. 点击“保存模板和节次”。

完成标准：至少一个模板、至少一个启用星期、至少一个可用节次，时间能容纳课程课长。

## 5. 第三步：学校数据

第一次排课时建立教师、班级和科目台账；后续排课直接复用本机构已有台账，只维护人员、班级或科目的实际变化。

1. 在“教师”录入姓名和分组标签。
2. 检查同名提示，用标签区分不同人员。
3. 在“班级”录入行政班和人数。
4. 在“科目”录入科目名称和默认课长。

完成标准：本次排课会引用的教师、班级、科目都能在台账中找到。

## 6. 第四步：教室设置

第一次排课时建立教室类型和教室台账；后续排课直接复用本机构已有数据，只维护教室、容量、类型或不可用时间的实际变化。

1. 先创建教室类型，例如普通教室、实验室、音乐教室。
2. 再创建具体教室并选择类型、填写容量。
3. 对不能使用的时间添加不可用规则：选择周频率、星期和节次。
4. 保存教室。

完成标准：需要教室的课程有可选教室；专用教室的不可用时间已经录入。

## 7. 第五步：课程计划与授课任务

沿用当前项目重新排课时，只局部调整课程计划、授课任务和课次；新建学期或独立排课项目时，需要在新项目中重新完成本节配置。

### 推荐按班级配置

1. 选择行政班。
2. 选择科目。
3. 新增或选择授课任务。
4. 选择教师；同一班级同一科目可有多个授课任务以支持多教师承担。
5. 选择“使用教室”或“不使用教室”。
6. 使用教室时添加默认候选教室。
7. 打开“编辑课次”，新增、复制、启用或删除课次。
8. 对每个课次按需设置候选时间、候选优先级和课次自定义教室。
9. 先在课次弹出栏点击“完成”，再回到右侧点击“保存授课任务”。

### 可选按教师配置

先选教师，再选班级和科目。此模式与按班级模式操作同一批数据，适合从教师工作量表录入。

完成标准：每个计划有授课任务，每个任务有实际课次；教师、教室和候选时间符合实际。

## 8. 第六步：约束配置

沿用当前项目重新排课时，只局部调整自定义约束并复核自动约束；新建项目时，应根据新配置的课次重新检查自动约束并配置本次需要的自定义约束。

1. 检查自动生成的教师、班级或教室保障约束；自动约束只读。
2. 用来源、权限和关键词筛选约束。
3. 新建自定义约束时优先选择“常见约束”。
4. 选择场景和关联课次。
5. 必须满足的规则勾选“硬约束”。
6. 可接受违反的偏好取消硬约束并设置违反扣分。
7. 保存后查看自然语言摘要、作用范围和编译状态。

完成标准：硬约束真实且必要，软约束权重合理，启用约束可以进入排课输入。

## 9. 第七步：排课前数据清单

1. 进入“排课运行”。
2. 点击“发起排课”。
3. 检查教师、班级、科目、教室、课程计划、授课任务、课次和约束数量。
4. 处理“必须处理”的阻塞问题。
5. 复核警告，例如未指定教师、使用教室但未选默认教室、不可编译约束。
6. 需要留档时点击“立即下载”，或勾选继续排课时同时下载 JSON 快照。
7. 点击“继续排课”。

临时 JSON 快照不包含账号、机构成员、历史候选课表、算法日志或 XML 文件。

## 10. 第八步：等待排课完成

运行状态依次体现准备数据输入、运行算法、解析候选课表。常见状态：

- 尚未发起。
- 已排队。
- 运行中。
- 已完成。
- 运行失败。
- 已终止。

运行中可以点击“终止排课”。重新排课会生成新的候选结果；不要把运行中的旧页面内容当作最终结果。

## 11. 第九步：校验候选课表

排课完成后检查：

- 未排入课次。
- 需要教室但缺少教室的课次。
- 硬约束违反。
- 软约束违反。
- 总质量和时间、教室、软约束惩罚明细。

若硬约束违反或有课次未排入，结果不能直接作为正式课表。返回相应页面修改数据或约束后重新排课。

## 12. 第十步：查看、导出和微调

### 查看

可切换全课表、按班级、按教师视图，并切换周次。

### 导出

可导出全课表、班级课表和教师课表 Excel。导出样式沿用“课表设置”的模板和课程单元格样式。

### 人工微调

1. 拖动课次，或先点击课次再点击目标位置。
2. 目标可为空时间槽、另一课次位置或缓冲区。
3. 查看移动警告。
4. 点击“确认移动”。
5. 等待系统重新计算校验和质量。
6. 再次确认没有新增硬约束违反或缺失。

缓冲区中的课次尚未处于正常课表位置，交付前应处理完毕。

## 13. 推荐验收清单

- 当前机构和项目正确。
- 学期周数、星期、节次正确。
- 教师、班级、科目、教室数量与资料一致。
- 每个授课任务的教师和课次数正确。
- 不需要教室的任务明确标记为“不使用教室”。
- 候选时间没有把可行范围限制得过窄。
- 硬约束违反为 0。
- 未排入为 0。
- 需要教室的课次缺少教室为 0。
- 班级和教师视图抽查无明显冲突。
- 微调后重新校验。
- 导出的 Excel 已抽查表头、节次和课次内容。
