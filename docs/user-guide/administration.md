# 管理员操作指南

## 1. 适用范围

当前用户界面主要区分：

- 机构成员：使用被授权的机构和项目功能。
- 机构管理员：管理机构成员、加入申请和机构状态。
- 平台管理员：审核机构注册申请，并管理机构 AI 月度额度。

产品设计资料中的排课负责人、教师、只读成员等更细角色属于规划模型，当前页面没有完整开放对应的细粒度权限配置。

## 2. 机构管理员入口

机构管理员可从侧边栏“管理机构”或个人中心进入机构详情。页面显示机构状态、成员数量和待处理加入申请。

## 3. 审核加入机构申请

1. 进入“管理机构”。
2. 在“加入申请”查看申请账号、状态和申请说明。
3. 核对申请人的身份和岗位。
4. 点击“通过”或“驳回”。
5. 通过后在成员列表确认账号已加入。

不要仅凭邮箱判断身份。正式机构应建立线下核验流程。

## 4. 管理成员

### 设置角色

1. 在“关联用户”找到成员。
2. 点击“设为管理员”或“设为成员”。
3. 确认角色变化符合职责分工。

### 移除成员

1. 找到目标成员。
2. 点击“移除”。
3. 确认该成员不再需要访问机构数据。

系统不允许管理员移除自己，也会保护最后一名机构管理员。需要交接时先将另一名成员设为管理员。

### 管理原则

- 管理员数量保持最少且至少两人，避免无人可管理。
- 人员离职或职责变化后及时调整。
- 定期复核成员名单。
- 不共用账号。

## 5. 注销机构

1. 进入机构详情。
2. 点击“注销机构”。
3. 确认项目数据、导出文件和成员访问已妥善处理。
4. 按提示完成操作。

注销机构是高影响操作，不等同于个人退出机构。正式使用前应先完成备份和内部审批。

## 6. 平台管理员：机构注册审核

平台管理员侧边栏会显示“平台审核”。

1. 打开机构注册申请列表。
2. 查看机构名称、申请人、手机号、微信号、地址和用途。
3. 按平台审核规则核验资料。
4. 点击“通过”或“驳回”。
5. 通过后系统创建机构，并将申请账号设为机构管理员。

平台管理员可点击“刷新”更新列表。

## 7. 平台管理员：AI 月度额度

1. 在“AI 月度额度”查看每个机构的已用、限额、剩余和使用比例。
2. 修改“月额度”。
3. 点击“保存额度”。
4. 通知机构管理员新的额度策略。

额度最小为 0，界面建议按 10,000 token 步长调整。调整前应结合机构规模、用途和成本政策。

## 8. 账号和机构异常处理

### 唯一管理员无法退出

先设置另一名成员为管理员，再退出；如果机构不再使用，走注销机构流程。

### 申请人找不到机构

要求使用机构完整名称精确查询，核对空格和字词。

### 审核通过后仍看不到机构

让用户退出登录并重新登录；必要时刷新工作台。仍未出现时由平台管理员检查申请状态和成员关系。

### 成员看到错误项目

让成员确认当前机构和顶部当前项目，再回工作台重新选择。

## 9. 安全检查清单

- 审核申请前完成身份核验。
- 机构至少保留一名有效管理员，建议两名。
- 不向无关人员授予管理员。
- 移除离职或不再参与人员。
- 定期检查平台管理员账号。
- AI 额度调整有记录和依据。
- 注销机构前完成数据保留和审批。
