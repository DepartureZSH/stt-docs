# 学校数据页面操作手册

## 1. 页面用途

学校数据页维护课程计划会引用的教师、行政班和科目。三类数据共用“左侧分类、中央台账、右侧新增/编辑表单”的工作区。

录入顺序不强制，但建议教师、班级、科目全部完成后再大批量配置课程计划。

## 2. 通用操作

### 切换分类

点击左侧“教师”“班级”或“科目”。分类右侧显示当前数量。

### 搜索和排序

- 在搜索框输入名称或相应字段。
- 点击表头可按名称、标签、人数或课长排序。
- 台账上方显示当前筛选数量和总数。

### 编辑

1. 在目标记录行点击“编辑”。
2. 右侧表单进入编辑状态。
3. 修改后点击“保存修改”。
4. 不保存时点击“取消编辑”。

### 删除

1. 在目标记录行点击“删除”。
2. 如果有关联课程计划或授课任务，系统显示级联删除清单。
3. 确认影响范围后选择“级联删除”或“取消”。

级联删除会同时删除关联数据，正式环境应谨慎操作。

## 3. 教师台账

### 新增教师

1. 切换到“教师”。
2. 在右侧输入姓名。
3. 添加一个或多个分组标签。
4. 点击“保存教师”。

### 分组标签

标签可用于教研组、班主任、年级或其他检索维度。可选择预设标签，也可输入自定义标签后按回车或点击“添加”。

建议至少使用一种能区分同名教师的标签，例如“数学组”“一年级”“班主任”。

### 同名教师

系统允许保存重名教师，但会显示同名提示和已存在记录。操作时：

1. 核对是否为同一人重复录入。
2. 如果确为不同人员，补充不同的分组标签。
3. 在排课前数据清单中再次查看重名提示。

### 快速筛选

- 全部。
- 只看同名。
- 班主任。
- 未分组。

## 4. 班级台账

### 新增班级

1. 切换到“班级”。
2. 输入班级名称，例如“一年级 1 班”。
3. 输入班级人数。
4. 点击“保存班级”。

班级名称建议包含年级和序号，并在同一机构内保持统一格式。

### 修改或删除班级

修改班级名称和人数后保存。删除班级时，系统可能列出关联课程计划和授课任务；只有在确定不再需要时才级联删除。

## 5. 科目台账

### 新增科目

1. 切换到“科目”。
2. 输入科目名称。
3. 输入默认课长，单位为分钟，最小 5 分钟，并以 5 分钟为步长。
4. 点击“保存科目”。

默认课长会用于新建课次。平台内部以 5 分钟时间单位换算，但普通用户只需维护分钟数。

### 修改默认课长

修改科目默认课长主要影响后续新建或重新生成的课次。已有课次是否同步变化应在课程计划页逐项确认。

### 课长与节次

如果课长超过某个节次可用时长，该节次不能作为候选时间。出现“所有节次时长不足”时，检查科目课长和课表模板时间。

## 6. 数据录入建议

- 先确定统一命名规则再批量录入。
- 教师重名时不要在姓名中随意追加隐含信息，优先用标签区分。
- 班级名称包含年级信息。
- 科目默认课长使用学校实际教学时长。
- 删除基础对象前先查清课程计划影响。

## 7. 完成检查

- 教师数量与任课资料基本一致。
- 同名教师已核对并用标签区分。
- 本次排课涉及的行政班全部存在。
- 所有课程名称和默认课长正确。
- 没有因搜索过滤误以为数据缺失。
